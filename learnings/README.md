# Learning archive

For revision, use the single [concept study guide](../LEARNING_NOTES.md).
It groups explanations and examples by concept rather than by day or test case.

The [session history](SESSION_HISTORY.md) preserves the former chronological
journal. The dated Markdown files preserve the original lesson records.
Historical pending tasks and verification counts refer to their original checkpoint.

Update the relevant concept in LEARNING_NOTES.md as understanding develops.
Keep session checkpoints in PROGRESS.md. Do not create new per-day/per-test records
or append tiny exercise logs to the study guide.
