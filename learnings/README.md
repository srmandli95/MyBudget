# Learning archive

For revision, use the single [MyBudget learning journal](../LEARNING_NOTES.md).
It contains the consolidated lessons in learning order with a contents list.

The dated Markdown files here preserve the original lesson records. Historical
pending tasks and verification counts refer to their original checkpoint.

Per the learner's preference, append each future lesson to LEARNING_NOTES.md
instead of creating another dated file. Update its contents list and PROGRESS.md.
