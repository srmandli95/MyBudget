# Decisions

## Begin with local Python

Use the installed Python interpreter and standard library for the first exercise.
Defer web frameworks, frontend tools, and external services until the corresponding
problems are understood. This keeps the first feedback loop small.

The learner implements core exercises before receiving reference solutions.
Use fictional financial records. Budgets will be configuration, not calculation logic.
Sample monthly USD limits: groceries 500, restaurants 200, gas 250, miscellaneous 150;
total 1100. Track subscriptions separately.
